# John Matthew Maneja — SEO Portfolio

A responsive, single-page portfolio website for GitHub Pages. The website uses plain HTML, CSS, inline SVG, and a small JavaScript reveal effect. No build tools or dependencies are required.

## Publish on GitHub Pages
1. Create a new GitHub repository. For a personal site, name it `YOUR-GITHUB-USERNAME.github.io`; otherwise any repository name works for a project site.
2. Upload `index.html`, `README.md`, and the `assets/` folder. Keep the folder structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the Pages deployment. GitHub will show the published URL in Settings → Pages.

## Before publishing
- Confirm the LinkedIn URL in `index.html` is your current profile URL.
- Update or remove the LinkedIn link if needed. A Facebook URL was not supplied, so no guessed Facebook profile link is included.
- The +200% graphic is explicitly labeled as illustrative, not a verified client outcome or guarantee.
- Sample Search Console figures are presented as separate reported snapshots, not combined into one campaign.
- Ensure the Google Drive case-study folder permissions allow recruiters to view the files.
- Review the overlapping employment dates and adjust if you want to clarify concurrent roles.
